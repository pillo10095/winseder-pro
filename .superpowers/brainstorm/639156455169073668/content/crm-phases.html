CRM Avanzado — Roadmap

8 módulos en 4 fases. Cada fase entrega valor real e independiente.

Fase 1 — Fundación + Pipeline 🎯

Backend sólido + Kanban de nivel enterprise. El pipeline ES el CRM.

  • UI/UX completa del pipeline con estados visuales avanzados
  • Drag & drop fluido con animaciones
  • Lead detail con timeline, actividades, WhatsApp integrado
  • Búsqueda y filtros combinados
  • Componentes UI premium (shadcn + custom)

Fase 2 — Contactos + Dashboard 📊

Gestión de contactos con labels, empresas, historia completa + dashboards en tiempo real.

  • Contactos con enriched data, histórico completo
  • Labels, empresas, vinculación con deals
  • Dashboard con KPIs, gráficos Recharts, filtro temporal
  • Métricas: leads por etapa, conversión, valor del pipeline

Fase 3 — Calendario + Automatización ⚡

Calendario interactivo + reglas de automatización + mensajes programados.

  • Vista semanal/mensual con drag & drop de actividades
  • Reglas: stage-based triggers, time-based, whatsapp-based
  • Message scheduler con preview
  • Integración con Baileys WhatsApp

Fase 4 — UX Global + Polish ✨

La cereza del postre. Transiciones, responsive, tema oscuro/claro, atajos de teclado.

  • Navegación global fluida con sidebar colapsable
  • Transiciones page-level con Framer Motion
  • Responsive mobile-first completo
  • Dark/light mode con next-themes
  • Keyboard shortcuts: n = nuevo, / = buscar, etc.

CRM Avanzado — Roadmap

8 módulos en 4 fases. Cada fase entrega valor real.

Fase 1 — Fundación + Pipeline 🎯

Backend sólido + Kanban de nivel enterprise.

  • UI/UX completa del pipeline con estados visuales avanzados
  • Drag & drop fluido con animaciones
  • Lead detail con timeline, actividades, WhatsApp integrado
  • Búsqueda y filtros combinados
  • Componentes UI premium

Fase 2 — Contactos + Dashboard 📊

  • Contactos con enriched data, histórico completo
  • Labels, empresas, vinculación con deals
  • Dashboard con KPIs, gráficos Recharts, filtro temporal

Fase 3 — Calendario + Automatización ⚡

  • Vista semanal/mensual con drag & drop
  • Reglas: stage-based triggers, time-based, whatsapp-based
  • Message scheduler + integración Baileys

Fase 4 — UX Global + Polish ✨

  • Sidebar colapsable, transiciones Framer Motion
  • Responsive mobile-first, dark/light mode
  • Keyboard shortcuts
